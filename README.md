# ABI Out-of-Stock (OOS) Copilot System

🚀 **Live Demo:** [Deploy link will be added here]

An AI-driven logistics copilot system for Anheuser-Busch InBev (ABI) to handle Out-of-Stock situations in the U.S. beer distribution market. The system automates the entire OOS resolution workflow from wholesaler request to delivery confirmation.

## Features

- ✅ **Actionable Dashboard** - Real-time alerts with one-click decision buttons
- ✅ **Wholesaler Management** - Comprehensive performance tracking & inventory monitoring  
- ✅ **Analytics Dashboard** - Business intelligence with predictive analytics & interactive charts
- ✅ **Configuration Management** - Network optimization with cost analysis
- ✅ **Interactive Network Map** - Visual route planning and distribution optimization

## Technology Stack

- **Frontend**: React with TypeScript, Material-UI
- **Backend**: Node.js with Express, TypeScript
- **Database**: PostgreSQL (ready for real data)
- **Authentication**: JWT-based authentication
- **Charts & Analytics**: Chart.js, D3.js

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- PostgreSQL (for production data)

### Installation

1. Install all dependencies:
```bash
npm run install:all
```

2. Start the development environment:
```bash
npm run dev
```
